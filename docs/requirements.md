# PocketSub 要件定義書

## 1. 概要

| 項目 | 内容 |
|---|---|
| アプリ名 | PocketSub |
| 種別 | サブスク・固定費管理アプリ |
| 位置づけ | ポートフォリオ用個人開発アプリ |
| 対象範囲 | 個人（単一ユーザー想定）のサブスクリプション管理 |

## 2. 背景・目的

近年、動画配信・音楽配信・クラウドストレージなど月額/年額課金のサービス（サブスクリプション）が増加し、契約状況の把握が難しくなっている。
本アプリは、ユーザーが契約中のサブスクを一覧で管理し、年間の固定費支出を可視化することで支出管理を支援することを目的とする。

併せて、Go言語によるバックエンドAPI開発力・PostgreSQLを用いたデータ設計力を示すポートフォリオ作品として開発する。

## 3. 想定ユーザー

- 複数のサブスクサービスを契約しており、支出を一元管理したい個人ユーザー
- 本アプリケーションのソースコードを閲覧する採用担当者・エンジニア（ポートフォリオとしての閲覧者）

## 4. 用語定義

| 用語 | 説明 |
|---|---|
| サブスク | 定期的に料金が発生する契約（サブスクリプション） |
| 支払いサイクル | 月額(monthly) / 年額(yearly) の課金周期 |
| 年間コスト | 各サブスクの料金を年額換算した金額の合計 |
| 更新日 | 次回の課金が発生する日付 |

## 5. 機能要件

### FR-01 サブスク一覧・カード表示
- 登録済みサブスクをカード形式の一覧で表示する
- 各カードには以下を表示する
  - サービス名
  - 料金（月額/年額）
  - 支払いサイクル
  - 次回更新日
- 一覧は次回更新日が近い順に表示する

### FR-02 年間コストの自動集計ダッシュボード
- 登録済み全サブスクの年間合計金額を自動計算して表示する
- 月額契約は「月額 × 12」、年額契約はそのままの金額を年間コストとして換算する
- 登録件数も併せて表示する

### FR-03 更新日アラート・ステータス
- 各サブスクについて「更新日まであと〇日」を表示する
- 残り日数に応じて視覚的なステータス（色分け）を行う
  - 3日以内: 警告（赤）
  - 7日以内: 注意（黄）
  - それ以外: 通常（緑）

### FR-04 ワンクリック追加・削除
- モーダルフォームからサブスクを新規登録できる
  - 入力項目: サービス名、料金、支払いサイクル、次回更新日
- 一覧の各カードから、確認なしで即座に削除できる
- 追加・削除後は一覧とダッシュボードの表示を即座に更新する

## 6. 非機能要件

### 6.1 技術スタック
- バックエンド: Go（標準ライブラリ `net/http` によるAPIサーバー）
- データベース: PostgreSQL（Supabase / Neon 等のマネージドサービスを想定）
- フロントエンド: HTML5 + Tailwind CSS + 素のJavaScript（フレームワーク不使用）
- 配信方式: Goサーバーが静的ファイル配信とJSON APIの両方を担う単一サーバー構成

### 6.2 パフォーマンス
- 個人利用規模（数十件程度のサブスク登録）を前提とし、特別なキャッシュ機構は設けない

### 6.3 セキュリティ
- データベース接続情報は環境変数で管理し、リポジトリに含めない
- SQLインジェクション対策としてプレースホルダ（プリペアドステートメント）を使用する

### 6.4 可用性・運用
- ローカル環境および無料枠のクラウドサービス（Supabase / Neon等）で動作することを前提とする

## 7. 制約条件

- 認証・認可の仕組みは持たない（単一ユーザー・個人利用前提）
- モバイルアプリとしては提供せず、レスポンシブなWebアプリとして提供する

## 8. スコープ外（対象外機能）

- 複数ユーザーによるログイン・認証機能
- メール・プッシュ通知による更新日リマインド
- クレジットカード等の決済連携・自動請求検知
- 支出のグラフ・カテゴリ別分析などの高度な分析機能（将来拡張候補）

## 9. 将来拡張案（参考）

- 更新日が近いサブスクのメール通知
- カテゴリ別（動画/音楽/仕事ツール等）の集計
- 支出推移のグラフ表示
